# GestureCode V1
Déploiement : pousser ces fichiers à la racine du repo → Settings > Pages > Deploy from branch (main, /root).
Gestes : ◯ arc/cercle = for · V = if · trait → = while · trait ↓ = else · zigzag = supprimer le bloc. Boutons de secours dans « Gestes ».
Run : sous-ensemble Java → JS (variables, boucles, if/else, System.out.println), sans classes. Ajouter un runner = entrée dans RUNNERS.
Après modification des fichiers, incrémenter `V` dans sw.js.
